# نُطق — مدرّب النطق الإنجليزي

تطبيق ويب لتعلّم نطق الإنجليزية للمتحدثين بالعربية: مدرّب الكلمات، مكتبة الأصوات الـ 44 مع رسوم الفم، تمارين الأزواج المتقاربة، الترديد (Shadowing)، والمحادثة بالتدريب الجاهز.

## النشر على GitHub Pages
1. ارفع كل الملفات إلى مستودع (Repository) عام.
2. Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
3. بعد دقيقة أو دقيقتين يظهر الرابط: `https://USERNAME.github.io/REPO/`

## ملاحظات
- يعمل بدون إنترنت بعد أول فتح. عند تحديث أي ملف، غيّر رقم `CACHE` في `sw.js` (مثلًا nutq-v2).
- خصائص الذكاء الاصطناعي تحتاج ربط الخادم الشخصي من الإعدادات. انظر تعليمات الإصدار 1.1 أدناه.

## تحديث 1.1 — النسخة الشخصية

- فصل قاموس الكلمات ومنطق التطبيق وإعدادات الاتصال في ملفات مستقلة.
- زر إعدادات عربي لربط خادم شخصي واختبار الاتصال دون استهلاك طلب مدفوع.
- مسار اتصال مستقل بدل الاعتماد على بيئة Claude؛ تعليمات التفعيل في `backend/README.md`.
- حفظ آخر 100 تصحيح لغوي محليًا، وعرض أحدث 20 للمراجعة في الإعدادات.
- توضيح الفرق بين التعرف على الكلمات وتقييم النطق المتخصص.
- الإبقاء على مفاتيح `nutq:` الحالية والتدريبات والقاموس ورسوم الأصوات والأزواج المتقاربة والترديد.
- تحديث ملفات التشغيل دون اتصال للإصدار `nutq-v3` مع حصر تنظيف الذاكرة المؤقتة في إصدارات نُطق فقط.

الخدمة لا تعمل فعليًا قبل نشر الخادم وإعداد مفاتيحه. المحادثة الصوتية المباشرة والتقييم الصوتي المتخصص مرحلتان تاليتان.
بعد تحديث الموقع، أغلق جميع صفحات نُطق والنسخة المضافة للشاشة الرئيسية ثم افتحه مجددًا لتنشيط الإصدار الجديد.

## اختبارات التطوير

اختبارات الخادم: `node --test tests/backend.test.mjs`. فحص التفاعل دون متصفح: ثبّت `jsdom` في بيئة التطوير وشغّل `node tests/dom.cjs`. اختبار المتصفح الكامل: ثبّت `playwright` وChromium، وشغّل خادمًا محليًا على المنفذ 8765 ثم `node tests/ui.cjs`.

تم التحقق من اختبارات الخادم وفحص DOM بردود ذكاء اصطناعي محاكاة. لم يُختبر الميكروفون على آيفون أو الاتصال المدفوع الفعلي بعد.

# نُطق — مدرّب النطق الإنجليزي

تطبيق ويب لتعلّم نطق الإنجليزية للمتحدثين بالعربية: مدرّب الكلمات، مكتبة الأصوات الـ 44 مع رسوم الفم، تمارين الأزواج المتقاربة، الترديد (Shadowing)، والمحادثة بالتدريب الجاهز.

## النشر على GitHub Pages
1. ارفع كل الملفات إلى مستودع (Repository) عام.
2. Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
3. بعد دقيقة أو دقيقتين يظهر الرابط: `https://USERNAME.github.io/REPO/`

## ملاحظات
- يعمل بدون إنترنت بعد أول فتح. عند تحديث أي ملف، غيّر رقم `CACHE` في `sw.js` (مثلًا nutq-v2).
- خصائص الذكاء الاصطناعي (التصحيح الذكي، الترجمة من العربية، الشريك الذكي، إنشاء الفقرات) تعمل داخل claude.ai فقط في هذه النسخة.

# تفعيل خدمة نُطق الشخصية

هذه الخدمة تفعّل المحادثة النصية والتصحيح والترجمة وإنشاء فقرات التدريب.
الصوت الحالي من المتصفح. لا تتضمن هذه المرحلة OpenAI Realtime أو Azure Pronunciation Assessment.

## الإعداد

يلزم حساب Cloudflare وحساب OpenAI API مع فوترة. اشتراك ChatGPT لا يغني عن حساب API.
من مجلد `backend`، بعد تثبيت Node.js:

```sh
npx wrangler login
npx wrangler secret put OPENAI_API_KEY
npx wrangler secret put PERSONAL_TOKEN
npx wrangler deploy
```

أنشئ رمزًا عشوائيًا شخصيًا للخادم بطول 24 حرفًا على الأقل (مثل رمز من مدير كلمات المرور).
احتفظ بالمفتاح الحقيقي في سر `OPENAI_API_KEY`، وأدخل رمز الدخول فقط في التطبيق.
بعد النشر، ضع عنوان Worker في ⚙ الإعدادات، وأدخل رمز الدخول، واضغط اختبار الاتصال.

يتذكر التطبيق العنوان فقط، ويحتفظ برمز الدخول في ذاكرة الجلسة دون تخزينه على القرص.
أدخله مجددًا بعد إغلاق التطبيق. لا تضع مفاتيح الخدمات في GitHub أو في ملف JavaScript.

## حدود التشغيل

الحد الافتراضي 30 محاولة يوميًا و300 شهريًا و6 في الدقيقة؛ يبدأ اليوم والشهر بتوقيت UTC.
كل محاولة محجوزة قبل الاتصال بالخدمة، ويُحسب الفشل كذلك للحد من إعادة المحاولة المكلفة.
الطلب لا يتجاوز 16000 حرف، والرد لا يتجاوز 2048 رمزًا لغويًا.
يمكن تعديل حدود الطلبات والنموذج من `wrangler.toml` ثم إعادة النشر.
هذه حدود طلبات، وليست سقفًا ماليًا بالدولار. اضبط ميزانية وتنبيهات الحساب لدى مزود الخدمة أيضًا.
فحص الاتصال لا يستهلك طلبًا مدفوعًا.

لا يسجل هذا الكود نص المحادثة على الخادم، لكن النص يُرسل إلى OpenAI لتنفيذ الطلب، وتطبق سياسة مزود الخدمة.
التصحيحات والتقدم تُحفظ على الجهاز بنفس أصل الموقع. الخادم شخصي؛ يلزم نظام حسابات قبل النشر التجاري.
